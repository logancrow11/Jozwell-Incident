# Jozwell-Incident

## Play

Open `index.html` in a browser. The game works without image files; missing images fall back to initials or are hidden.

To add the character photos, place these JPEGs beside `index.html`:

- `photo.jpg` for the diver and the rarest tier
- `george.jpeg` for the George tier
- `brat.jpg` for the Brat tier
- `britney.jpg` for the Britney tier

Use the `.jpg` filenames exactly as shown. The question editor and game settings save in the current browser.
